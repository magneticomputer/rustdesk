**Magnetic Support** è l'applicazione ufficiale di assistenza remota di [Magnetic](https://magnetic.computer).
Consente a un tecnico autorizzato di collegarsi a un dispositivo, previo consenso dell'utente,
per fornire supporto. La connessione è cifrata end‑to‑end e passa esclusivamente attraverso i
server di Magnetic.

- **Sito e download:** https://support.magnetic.computer
- **Privacy policy:** https://support.magnetic.computer/privacy.html
- **Contatti:** info@magnetic.computer

## Piattaforme

Windows, macOS, Android e iOS. Gli installer sono disponibili nella
[pagina dei download](https://support.magnetic.computer) e nelle
[release](https://github.com/magneticomputer/rustdesk/releases).

## Come funziona

1. Scarica e apri **Magnetic Support** sul dispositivo da assistere.
2. Comunica al tecnico l'**ID** e la **password** mostrati dall'app.
3. Il tecnico si collega; la sessione è visibile sullo schermo e interrompibile in qualsiasi momento.

L'app è preconfigurata per collegarsi automaticamente ai server di Magnetic: nessuna configurazione
richiesta all'utente.

## Build

Le applicazioni vengono compilate automaticamente tramite GitHub Actions
(`.github/workflows/magnetic-build.yml`) per tutte le piattaforme.
